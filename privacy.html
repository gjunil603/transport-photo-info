개인정보처리방침

시행일: 2026년 9월 7일

1. 적용 대상

이 개인정보처리방침은 Android 앱 ‘탁송 기록’(패키지 이름: com.personal.transportphoto)에 적용됩니다.

2. 앱이 처리하는 정보

앱은 사용자가 입력하거나 선택한 탁송 날짜, 차량번호, 메모, 운행 구간, 사진 파일과 사진의 촬영정보를 휴대폰 내부 앱 저장공간에 보관합니다. 개발자는 이러한 정보를 전송받거나 별도 서버에 수집하지 않습니다.

3. 사진 및 미디어 접근

앱은 사용자가 선택한 사진을 기록에 추가하고, 기본 카메라로 촬영한 사진을 찾으며, 사용자가 요청한 원본 정리를 수행하기 위해 Android 사진·미디어 접근 권한을 사용합니다. 원본 삭제 또는 휴지통 이동이 필요한 경우 Android가 제공하는 사용자 확인 절차를 따릅니다.

4. Google 사용자 데이터 및 Drive

Google Drive 백업은 선택 기능입니다. 사용자가 기능을 켜고 Google 계정 권한을 승인한 경우에만 https://www.googleapis.com/auth/drive.file 권한을 사용합니다.

  • 접근 목적: 앱에서 관리하는 사진의 폴더 생성, 업로드, 이동 및 백업 무결성 확인
  • 접근 범위: 앱이 사용자의 Drive에서 생성하거나 앱에 허용된 파일
  • 저장 위치: 사용자가 선택한 본인의 Google Drive
  • 개발자 전송: Google 사용자 데이터는 개발자 서버로 전송되거나 판매·광고·분석에 이용되지 않음
  • 공유: 법률상 요구되는 경우를 제외하고 개발자가 제3자에게 제공하지 않음

Drive 연결을 끄면 새로운 자동 백업이 중단됩니다. 이미 업로드된 파일은 사용자가 자신의 Google Drive에서 확인하거나 삭제할 수 있습니다.

5. 외부 공유

카카오톡 공유 등 Android 공유 기능은 사용자가 직접 선택한 사진에 한해 실행됩니다. 공유 대상 선택과 최종 전송은 사용자가 수행하며, 전송 이후에는 해당 서비스의 개인정보처리방침이 적용됩니다.

6. 보관 및 삭제

휴대폰에 저장된 앱 기록과 앱 보관본은 사용자가 직접 삭제하거나 설정한 자동 보관기간에 따라 정리됩니다. 자동 정리는 Drive 백업 파일이 존재하고 내용이 일치하는 경우에만 앱 보관본을 대상으로 실행됩니다. 앱을 삭제하면 앱 내부 기록과 앱 보관본은 삭제되지만, 휴대폰 갤러리 원본과 Google Drive 사본은 별도로 남을 수 있습니다.

7. 보안

앱은 서버 계정이나 자체 회원정보를 운영하지 않으며 Android 앱 전용 저장공간과 Google의 계정 승인 절차를 사용합니다. 다만 휴대폰 분실, 계정 탈취 또는 사용자가 제3자 서비스로 공유한 이후의 위험까지 완전히 방지할 수는 없습니다.

8. 사용자 선택권

사용자는 Google Drive 백업을 사용하지 않고 앱을 오프라인으로 사용할 수 있습니다. Android 설정에서 사진 접근 권한을 변경하고, Google 계정의 보안 설정에서 앱 접근 권한을 철회할 수 있습니다.

9. 방침 변경 및 문의

앱 기능이나 데이터 처리 방식이 변경되면 이 문서를 갱신하고 시행일을 수정합니다. 개인정보 또는 앱 사용 문의는 jjirailgun@gmail.com으로 연락할 수 있습니다.
